Install on your Garmin watch

Last updated: August 27, 2026

The ELEMENT | 08 watch app is not on the Connect IQ store, and it will not be. Garmin does not list apps for freediving, scuba, skydiving or base-jumping at all, as a blanket category rule rather than a judgement about this app. So you install it yourself, by copying one file to your watch over USB. It takes about two minutes.

// BEFORE YOU START

This app does not make breath-hold training safe. Never train in or near water alone, and never without a trained buddy within arm's reach. A watch cannot rescue you and neither can a spectator. Read Safety & Contraindications first if you have not.

You also need the ELEMENT | 08 phone app (iPhone or Android) to build sessions and receive results. The watch app on its own has nowhere to send your dives.

// STEP 1 · DOWNLOAD THE FILE FOR YOUR WATCH

Each watch model needs its own file. Picking the wrong one is the most common mistake, and the watch will simply ignore it.

Download

// STEP 2 · CONNECT THE WATCH

Plug the watch into your computer with its charging cable. Use a cable you know transfers data: many charging cables carry power only, and a power-only cable is the second most common reason nothing appears.

// STEP 3 · COPY THE FILE

The file goes into the folder GARMIN/APPS on the watch.

Windows

  1. Open File Explorer. The watch appears as a device, usually under This PC.
  2. Open Internal Storage, then GARMIN, then APPS.
  3. Drag the .prg file you downloaded into that folder.
  4. Eject the watch and unplug it.

macOS

macOS cannot open Garmin watches on its own, because Apple only supports its own media devices over this connection. You need one free tool:

  1. Install OpenMTP, which is free and open source.
  2. Quit Garmin Express first. Garmin Express and OpenMTP both claim the watch and will not work at the same time. This is the single most common reason the watch does not appear.
  3. Open OpenMTP. The watch shows on one side, your Mac on the other.
  4. Navigate to GARMIN, then APPS, and copy the .prg file across.
  5. Eject the watch in OpenMTP and unplug it.

// STEP 4 · FIND IT ON THE WATCH

Unplug the watch. ELEMENT | 08 now appears in your activity list, alongside the built-in activities. Start it there.

To send a session to it, open the phone app, build a session, and use the watch as the target. Both apps need to be open while a session transfers.

// IF SOMETHING GOES WRONG

  • The file vanished from GARMIN/APPS. That is correct and expected. The watch moves installed apps into its own storage, so the folder looks empty again. Check your activity list instead.
  • The watch does not appear at all. On macOS, quit Garmin Express and any other file-transfer tool, then reconnect. On either system, try a different cable: power-only cables are common.
  • The app is not in the activity list. You almost certainly copied the file for a different watch model. Go back to step 1 and check the model name carefully, including the case size.
  • Still stuck? Write to apnea.advantage@gmail.com and say which watch you have and which system you are on.

// UPDATES

Because the app is not on the Connect IQ store, it will not update itself. When a new version is released, come back to this page and copy the new file over the old one the same way.
